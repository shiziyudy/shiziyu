4. 建议部署到 GitHub Pages（独立于旧店铺网站）
------------------------------------------------
旧网站：https://in23555.github.io/shiziyu/
旧仓库是其他公司/店铺资料，不要覆盖它。

建议新建一个公开仓库（举例名称 dongying-shiziyu）：
  a) 登录 GitHub 账号 in23555。
  b) 创建一个新的 Public repository，命名 dongying-shiziyu。
  c) 把本 ZIP 解压后的文件直接上传到仓库根目录，确保根目录有 index.html。
  d) 打开新仓库 Settings -> Pages。
  e) 在 Build and deployment 里选择 Deploy from a branch，Branch 选 main，Folder 选 /(root)，保存。
  f) GitHub Pages 公布网站后，访问主页和 /privacy.html 检查。

如果仓库名称确为 dongying-shiziyu，预期网址是：
  https://in23555.github.io/dongying-shiziyu/

注意：这是按命名规则推导的【预期网址】，不是已发布的网址。
只有成功部署且能从浏览器公开访问后，才在亚马逊表单“组织网站”填写它。
